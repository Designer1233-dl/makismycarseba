# Telegram-бот для Сайт-Севы

1. Создай бота через `@BotFather` и скопируй токен.
2. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN` токеном от BotFather и `CODE_SECRET` длинной случайной строкой. Файл `.env` нельзя публиковать в Git.
3. Установи Python 3.11+ и зависимости:
   `pip install -r requirements.txt`
4. Запусти API и бота командой `python seva_auth.py` — настройки загрузятся из `.env` автоматически.
5. В `index.html` уже указан бот `@seva_Sot_Set_bot`; если изменишь username, замени его в тексте страницы и deep-link настройке.
6. В `index.html` замени `http://localhost:8000` на публичный HTTPS-адрес API.

Безопасность уже заложена в коде: коды случайные, хранятся только в виде HMAC-хеша, действуют 10 минут, одноразовые, после 5 неверных попыток блокируются. Telegram ID уникален в базе, поэтому один Telegram-аккаунт не сможет создать второй аккаунт сайта. Для продакшена используй HTTPS, задай постоянный `CODE_SECRET` и ограничь `ALLOWED_ORIGINS` доменом сайта.
